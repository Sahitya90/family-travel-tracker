# 🌍 Family Travel Tracker

A dynamic full-stack Node.js & PostgreSQL web application to track visited countries across multiple family user profiles on an interactive SVG world map.

## 🚀 Features
- Multi-user support with custom map highlighting colors
- Asynchronous dynamic map updates using `fetch()` API
- Database interaction via PostgreSQL (`pg`) with EJS rendering

## 🛠️ Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **Frontend:** EJS, HTML5, CSS3, JavaScript (ES6+)
